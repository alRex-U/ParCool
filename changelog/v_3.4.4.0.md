### New Features

- Grappling Hook
    - New item
        - Physics based rope swinging
        - Aim assist cone, used only when the crosshair itself misses

### Modified

- ParCool Action API
    - `ActionOption.needLearning` : lets an action opt out of skill tree gating, for abilities that
      are already gated by something else such as an item
    - `ActionOption.availableWhileExhausted` : lets an action run on empty stamina, for abilities
      that are not paid for with stamina
