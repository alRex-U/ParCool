# スキルツリー

![](parcool:skilltree)

これを読んでるっていうことは <item id="parcool:parcool_guide"/> を使っているということだと思います。
これをスニークして使うとスキルツリーを開くことができます。

ここでは経験値を消費することで、ParCoolの機能をアンロックできます。追加で機能のオンオフもできます。

左側の領域がスキルツリーです。そこから確認したいアクションを選択してください。

アクションのアイコンをクリックすると、右側の領域に選択したアクションが表示されます。
そこでアンロックのためのコストを確認できます。もし経験値が足りていれば、アンロックボタンを押すことができます。

もし既に解禁済みなら、ガイドを開くページと切り替えボタンが表示されます。
