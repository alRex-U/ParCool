# スキルツリー

![](parcool:skilltree)

ParCool には**スキルツリー**システムが存在し、
<key name="key.parcool.open_setting_skilltree"/> キーを押すことでスキルツリーを開くことができます。

ここでは経験値を消費することで、ParCoolの機能をアンロックできます。

左側の領域がスキルツリーです。そこから確認したいアクションを選択してください。

アクションのアイコンをクリックすると、右側の領域に選択したアクションが表示されます。
そこでアンロックのためのコストを確認できます。もし経験値が足りていれば、アンロックボタンを押すことができます。
