# チュートリアル

**ParCool**を遊んでくれてありがとうございます!
ParCoolは*クール*な*パルクール*のようなアクションを追加するMODです。
パルクールプレイヤーとして、ワールドを走り回りましょう！

このページでは、このMODで最初に見るべき要素をご紹介します。

## スタミナ

まずスタミナシステムを説明しなければなりません。

![](parcool:stamina)

ParCoolはスタミナを追加します。これはプレイヤーの短期的な疲労状態を表しており、ホットバーの空腹ゲージの上に表示されます。

ほとんどのParCoolアクションはスタミナを消費し、休憩中は時間経過で回復します。
スタミナが枯渇するとアクションが使用できなくなります。

## スキルツリー

よし、では次に [スキルツリー](parcool:skilltree.md) を見てみましょう!
スキルツリーは経験値を消費することで、以下の紹介しているものを含む機能を解禁することができます。さらに、各機能をオンオフすることも可能です。

## ファストラン

[ファストラン](parcool:actions/fast_run.md)はこのMODでも基本的なアクションです。文字通り通常より速く走ることができます。

さらにファストランは他の多くのアクションの基礎になるものでもあります。ぜひご活用ください。

操作は簡単で、デフォルトでは走っている間に <key name="key.sprint"/> キーを押し続けるだけです。

## ヴォールト

ファストランから派生するアクションがいくつかあります。その一つは [ヴォールト](parcool:actions/vault.md) です。
ヴォールトは実際のパルクールの技としても知られており、障害物を素早く飛び越えるために用いられます。

ファストランをしている間にブロックに衝突すると自動的に発動します。
フェンスのような1.5ブロックの障害物を乗り越えることも可能です。

### 空中ヴォールト

ヴォールトは空中でも使用できます。空中ヴォールトを上手く使えば、2ブロックの高さの障害物も素早く乗り越えられます。
見た目は難しいかもしれませんが、慣れれば簡単ですよ。

## 崖つかまり

高い壁や障害物を乗り越えたいときってありますよね。そんな時は [崖つかまり](parcool:actions/hang_on.md) の出番です。

使うのは簡単で、崖の近くで <key name="key.parcool.hang"/> キーを押すだけです。

さらに、<key name="key.jump"/> キーを押して[よじ登り](parcool:actions/climb_up.md)を使えば、ブロックの上に登ることもできます。
この組み合わせを使えば、最大で3ブロックの高さまで登れますよ！

ParCoolでは技の組み合わせ次第で、5ブロックの高さまで登ることもできます！詳しくは各アクションの説明をご覧ください。

## ブレイクフォール

ここでもう一つ重要なテクニックを紹介します。[ブレイクフォール](parcool:actions/breakfall)です。

これもまた実際のパルクールの技として知られており、着地の衝撃を和らげる技術全般を指します。
ゲーム中でも受ける落下ダメージを抑えることができます！

使うには着地する時に <key name="key.parcool.breakfall"/> キーを押すだけです。

## Zipline

そしてもう一つ、[ジップライン](parcool:zipline.md)を紹介させてください。

これを使うにはいくつかのアイテムをクラフトする必要があります。

まずはジップラインフックを作りましょう！二種類が存在します。どちらがお好みですか？

<recipe id="parcool:wooden_zipline_hook"/>
<recipe id="parcool:iron_zipline_hook"/>

それらをクラフトしたら、フックを好きな場所に配置してください。

次にジップラインロープを作りましょう。

<recipe id="parcool:zipline_rope"/>

革の防具と同じように染料で色を付けることができます。

スニークして使用するとロープの張力を変えることができます。そうしたら二つのジップラインフックに使用してください。

あとは <key name="key.parcool.hang"/> キーを押して[ジップラインに乗る](parcool:actions/ride_zipline.md)ことができます！
