# ウォールラン

[水平ウォールラン](parcool:actions/horizontal_wall_run.md)と混同しないように。これは走るというよりはジャンプに近いものです。
ただし、それでもかなり便利なアクションですよ。

壁を蹴ることで垂直方向により高くジャンプできます。
[崖つかまり](parcool:actions/hang_on.md)や[よじ登り](parcool:actions/climb_up.md)と併用すると最大で5ブロックの壁を上ることができます。
これはParCoolで乗り越えられる壁の高さでも最大です！

## 使い方

1. [ファストラン](parcool:actions/fast_run.md)をする
2. <key name="key.jump"/> キーを押しながら上を向いて壁に向かってジャンプする
