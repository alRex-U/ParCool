# グラップルを使う

*グラップリングフック*は追加の立体的な機動力を与える装備品です。

詳細は[グラップル](parcool:grapple.md)をご覧ください。

<item id="parcool:grappling_hook"/>は手に持つことで装備できます。

装備している間、画面の中央にグラップルの照準が表示されるはずです。
<key name="key.attack"/> キーを押すことでフックが発射されます。
さらにフックがブロックにかかった後、<key name="key.use"/> キーを押すとワイヤーを巻き上げることができます。

<item id="parcool:grappling_hook"/>の巻き上げる力は重力に逆らってプレイヤーを引き上げられるほど強くありません。
このため、上方向に移動する手段としてはあまり役に立たないでしょう。

しかし依然として水平方向の移動には便利ですし、高所にフックをかけることによってスイングするような動きも可能です。
