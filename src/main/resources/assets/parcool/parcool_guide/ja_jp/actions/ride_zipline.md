# ジップラインを使う

設置した[ジップライン](parcool:zipline.md)を使うことができます。
ジップラインの設置に関しては[こちら](parcool:zipline.md)のページをご覧ください。

注意点として、<item id="parcool:traceur_glove"/>なしでパワードジップラインを使用するとダメージを受けてしまいます。
<item id="parcool:traceur_glove"/>については[装備](parcool:equipments.md)のページをご覧ください。

## 使い方

1. ジップラインの近くへ移動する
2. 空中で <key name="key.parcool.hang"/> キーを押し続ける
