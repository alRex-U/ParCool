# ヴォールト

*ヴォールト*はパルクールでも有名なテクニックであり、障害物を飛び越えるためのアクションです。
1.5ブロックのフェンスのような障害物を乗り越えることもできます。

ヴォールトは多くの種類がありますが、ParCoolにはいくつかの特殊なアニメーションもあります。

## ヒント

ヴォールトはフェンスを飛び越えるだけのものだと思っていませんか？ 実はヴォールトは2ブロックの高さを飛び越えることもできます！
これは**空中ヴォールト**と呼ばれています。見た目ほどは難しくありません。高い障害物に飛び込んでヴォールトを使うだけです。
