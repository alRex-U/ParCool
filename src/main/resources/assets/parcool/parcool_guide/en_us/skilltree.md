# Skill Tree

![](parcool:skilltree)

ParCool provides **Skill Tree** system. Press <key name="key.parcool.open_setting_skilltree"/> to open Skill Tree menu.

You can unlock ParCool features from skill tree by consuming your experience.

All unlock-able actions are displayed in the largest area of screen.
You can select what you want to check its status.

When you click action icons, the selected action will be displayed on right of screen.
You should find the unlock cost there. If you have enough experience to unlock it, you can press unlock button.
