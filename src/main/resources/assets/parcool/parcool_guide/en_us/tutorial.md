# Tutorial

Thank you for playing **ParCool**!
ParCool is a mod to enable you to *Cool* actions like *Parkour*.
Now you become a parkour-player. Let's run around the Minecraft World!

In this page, I'll introduce contents which you should play first!

## Stamina

First I have to introduce Stamina system.

Player has a new parameter called Stamina. This expresses player's short-term fatigue.

Stamina is displayed above saturation of hotbar.

Almost ParCool actions consume stamina, and it recovers in relatively short time while resting.
You get these penalty when stamina is depleted.

- Disable to do almost all ParCool movement

## Skill Tree

Ok, so next let's see [Skill Tree](parcool:skilltree.md)!
You can unlock ParCool features from skill tree by consuming your experience, including following features!
Additionally, you can disable and enable whichever you want to.

## Fast Run

[Fast Run](parcool:actions/fast_run.md) is basic movement of ParCool. You can run faster than normal sprint.

In addition. Fast Run is base of other movements. Please make use of it.

Its control is easy too, with default setting, just press <key name="key.sprint"/> key while you running.

## Vault

There are some actions derived from Fast Run. One of them is [Vault](parcool:actions/vault.md).
Vault is one of actual parkour skill, jumping over obstacles quickly.

It's automatically triggered by colliding to blocks while fast running

Also, Vault makes it possible to get over fences.

### Technique - In-air Vault

You can vault in air. By utilize in-air vault it is possible to get over 2 blocks height obstacle quickly. It may look
difficult but actually quite easy.

## Hang On

I think there are times when you might want to climb up more high wall or obstacles. So it's time to
use [Hang On](parcool:actions/hang_on.md) movement!

It's easy to use. Just press <key name="key.parcool.hang"/> key and touch edge of blocks.

Additionally, You can [Climb Up](parcool:actions/climb_up.md) to jump up onto the block by
pressing <key name="key.jump"/> key. Thanks to it, it's possible even to overcome 3 block height obstacles!

ParCool enable even getting over 5 block height obstacles with combination of some movements. Please read pages of each
actions for details.

## Breakfall

Here's one more important feature. [Breakfall](parcool:actions/breakfall).

It's also known as actual parkour skill. This is a collective term of techniques which absorb/reduce impact of landing.
You can take less landing damage by using these skills in game!

It's also easy to use. Just press <key name="key.parcool.breakfall"/> key on landing.
