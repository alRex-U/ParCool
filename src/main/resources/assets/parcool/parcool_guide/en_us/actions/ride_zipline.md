# Ride Zipline

You can use placed [zipline](parcool:zipline.md).
Please see [this page](parcool:zipline.md) about how to place ziplines.

As a point to note, you take damage if you use *powered zipline* without <item id="parcool:traceur_glove"/>.
Please see [equipments](parcool:equipments.md) about how to make <item id="parcool:traceur_glove"/>.

## How to use

1. go near zipline you want to use
2. Continue to press <key name="key.parcool.hang"/> in air
