# Vault

*Vault* is a famous techniques of parkour to get over obstacles quickly.
You can get over even 1.5 block height obstacles like fences.

As vault has many variant movements, ParCool also provide some special animations.

## Tips

Do you think *Vault* is only for overcome fences? No, actually Vault enable you to jump over 2 block height obstacles.
I call the technique **In-Air Vault**, not so difficult techniques than it seems.
Simply jump into tall obstacles to trigger *Vault*

1. Run to obstacles with doing [Fast Run](parcool:actions/fast_run.md)
