## Climb Up

Now you don't have to place blocks for getting over wall!  
*Climb Up* is an action derived from [Hang On](parcool:actions/hang_on.md).  
This is one of most basic actions of ParCool, which enables you to climb up ledge which you are hanging on.

## How to use

1. Press <key name="key.jump"/> key while you are using [Hang On](parcool:actions/hang_on.md)
