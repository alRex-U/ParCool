# Horizontal Wall Run

Now you can run along walls, I think it might seem to be like Ninja.

You have to unlock [Fast Run](parcool:actions/fast_run.md) first to use this action.

## Hot to use

1. Do [Fast Run](parcool:actions/fast_run.md)
2. Jump to face of wall and press <key name="key.parcool.horizontal_wall_run"/>
