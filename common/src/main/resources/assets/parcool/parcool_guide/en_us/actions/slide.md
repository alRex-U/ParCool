# Slide

*Slide* is an action derived from [Crawl](parcool:actions/crawl.md), it enables you to go through narrow spaces quickly.

You have to unlock [Fast Run](parcool:actions/fast_run.md) first to use this action.

## How to use

1. Do [Crawl](parcool:actions/crawl.md) while doing [Fast Run](parcool:actions/fast_run.md)
