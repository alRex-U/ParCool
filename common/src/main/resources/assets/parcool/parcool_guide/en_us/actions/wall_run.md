# Wall Run

Don't mistake this for [Horizontal Wall Run](parcool:actions/horizontal_wall_run.md).
This is rather similar to jump than running. However, I'm sure this is especially useful action in this mod.

You can kick wall to jump more vertically to climb up the wall.
By using with [Hang On](parcool:actions/hang_on.md) and [Climb Up](parcool:actions/climb_up.md), you can get over 5
block height obstacles at maximum!
This is the max height that you can get on with this mod.

## How to use

1. Do [Fast Run](parcool:actions/fast_run.md)
2. Run and jump into wall, with looking upward and pressing <key name="key.jump"/> key
