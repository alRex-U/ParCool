# ジップライン

ParCool は**ジップライン**という設備を追加します。
ジップラインは二か所の**ジップラインフック**を結ぶロープです。ロープに沿って移動するために使用できます。

## ジップラインの設置

まず配置したい場所に*ジップラインフック*を設置しましょう。
二種類のジップラインフックが利用できます。

<recipe id="parcool:wooden_zipline_hook"/>
<recipe id="parcool:iron_zipline_hook"/>

では次に <item id="parcool:zipline_rope"/> を作成しましょう。

<recipe id="parcool:zipline_rope"/>

ロープは染色可能です、染料と一緒にクラフトすることで色を付けることができます。  
Shift を押しながら使用すると張力を変更できます。

準備ができたら、ロープを配置したフックに使用してジップラインをせっちできます。

## 使い方

[Ride Zipline](parcool:actions/ride_zipline.md) をご覧ください。

## パワードジップライン

フックにレッドストーン信号が入力されているとき、ジップラインは*パワードジップライン*になります。
パワードジップラインはプレイヤーを加速させ、ジップライン上を上昇することも可能です。

注意点として、<item id="parcool:traceur_gloves"/> を使わずにパワードジップラインを使用するとダメージを受けてしまいます。  
<item id="parcool:traceur_gloves"/> については [equipments](parcool:equipments.md) をご覧ください。
