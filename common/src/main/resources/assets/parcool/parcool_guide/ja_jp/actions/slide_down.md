# 壁滑り

[ブレイクフォール](parcool:actions/breakfall.md)のように、ParCoolにはいくつかの落下ダメージを軽減するアクションが存在します。
*崖滑り*はそのようなアクションの一つであり、壁との摩擦によって減速することができます。

<item id="parcool:traceur_glove"/>を装備していないと、わずかですがダメージを受けてしまいます。
<item id="parcool:traceur_glove"/>については[装備](parcool:equipments.md)のページをご覧ください。

1. 壁の傍で落下中に <key name="key.parcool.slide_down"/> キーを押し続ける
