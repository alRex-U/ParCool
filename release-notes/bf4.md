# Blockfield/parcool-fabric bf4

## Кратко

Первый релиз форка ParCool для Blockfield: перенос мода (апстрим ParCool 3.4.3.3) на Fabric 1.21.1, плюс три доработки под пак — блокировка спринта при истощении стамины собственным маркером, бесконечный бег FastRun без траты стамины и совместимость анимаций ParCool с позой оружия TaCZ.

## Для игроков

Новое/исправления: при полном истощении стамины бег теперь блокируется собственным маркером ParCool, а не гонкой состояний с ванильным спринтом — это убирает дёрганье персонажа при исчерпании стамины. Ускоренный бег (FastRun) больше не тратит стамину и не истощает её. Анимации ParCool (перекаты, скольжение и т. п.) больше не перебивают позу удержания оружия TaCZ.
Остальные коммиты промежутка — сам перенос ParCool 3.4.3.3 с исходной платформы на Fabric 1.21.1 и апстримные правки зиплайна, синхронизации стамины/действий и анимаций (переходы `SlidingAnimator`/`JumpChargingAnimator`, приоритет катания на зиплайне над нырком, сохранение относительной позиции крюка зиплайна, формат зелья в книге Patchouli) — их собственный игровой эффект в заголовках коммитов не детализирован.

## Технические изменения

CI: публикация jar на тегах `bfN`, сборка ограничена 30 минутами на Java 21. Перед портом проведена развязка клиентских классов и проверка на тестовом стенде. Синхронизация состояния действий и стамины по сети оптимизирована (дважды за промежуток). `ZiplineRopeEntity` получил bounding box для отсечения культингом. Убрано полное сканирование класса через `@SubscribeEvent` (точечная подписка вместо него). Добавлен `EpicFightStaminaHandler` для совместимости с EpicFight.

## Обновлённые компоненты

- ParCool: перенесённая версия апстрима — 3.4.3.3 (в коммитах видны промежуточные версии 3.4.3.0 и 3.4.3.1 по ходу порта на Fabric 1.21.1).
- Добавлена точка совместимости с EpicFight (`EpicFightStaminaHandler`).
Версий других сторонних зависимостей в этом промежутке не менялось.

## Совместимость и необходимые действия

Мод действует на обеих сторонах: правки стамины/действий синхронизируются по сети (сервер), анимации и совместимость с TaCZ — клиентские. Пин пака нужно обновить одновременно на клиенте и на сервере.

Сведений нет — в коммитах промежутка открытые проблемы не упоминаются.
