# Blockfield/parcool-fabric bf5

## Кратко

Точечное исправление: если клавиша ползания (Crawl) совпадает с клавишей уклонения (Dodge) — как в стандартной раскладке Blockfield (C) и как в раскладке по умолчанию у самого ParCool, — ползание из положения стоя стало снова работать. Второй коммит — только документация репозитория.

## Для игроков

Исправление: уклонение (Dodge) требует зажатого направления движения, чтобы отличить его от ползания, поэтому стоя на месте игра не могла понять, какое действие нужно, и не давала заползти на клавише, общей для Crawl и Dodge. Теперь ползание с этой клавиши работает и стоя на месте.
Остальных игровых изменений в промежутке нет — второй коммит добавляет только пояснение в README о том, как форк попадает в сборку Blockfield.

## Технические изменения

Правка в `com.alrex.parcool.common.action.impl.Crawl` разруливает совпадение клавиш Crawl/Dodge без зажатого направления движения.

## Обновлённые компоненты

Изменений версий зависимостей в этом промежутке нет — правка внутри самого форка.

## Совместимость и необходимые действия

Изменённый файл (`Crawl.java`) лежит в общем (`common`) пакете действий ParCool, то есть код единый для клиента и сервера — по коммиту нельзя точно определить, исполняется ли конкретно эта проверка только на клиенте. Пин пака безопаснее обновить на обеих сторонах вместе.
